# Compressible circular-arc bump cases

This directory contains subsonic, transonic, and supersonic bump-flow cases for the pressure-based compressible SIMPLE solver. All three use `flow_model = compressible`; no density-based or Riemann-flux solver is used.

## Geometry

The channel is `0 <= x <= 3`, `0 <= y <= 1`. A circular-arc bump occupies `1 <= x <= 2` on the lower wall. For chord `c = 1` and bump height `h`,

```text
R = (h^2 + (c/2)^2)/(2h)
y_lower(x) = h - R + sqrt(R^2 - (x-1.5)^2),  1 <= x <= 2
```

The subsonic and transonic meshes use `h = 0.1`; the supersonic mesh uses `h = 0.04`. Each is a body-fitted `90 x 24` quadrilateral grid (2,160 cells). Meshes are generated by `cases/generate_thermal_meshes.py` and written to `mesh/bump_10.msh` and `mesh/bump_04.msh`.

## Flow conditions

| Case | Prescribed inlet state | Outlet | Other boundaries |
|---|---|---|---|
| Subsonic | Total pressure `101325 Pa`; total temperature `315 K`; flow direction `(1, 0)` | Static pressure `84606.375 Pa` | Slip walls and adiabatic walls |
| Transonic | Total pressure `140513.23 Pa`; total temperature `316.224 K`; flow direction `(1, 0)` | Static pressure `101300 Pa` | Slip walls and adiabatic walls |
| Supersonic | `M = 1.4`; velocity `486.0641933 m/s`; static temperature `300 K`; absolute pressure `101325 Pa` | Zero-gradient velocity, pressure, and temperature | Slip walls and adiabatic walls |

All three cases are strictly inviscid (`viscosity = 0`, `thermal_conductivity = 0`, `viscous_dissipation = false`) and use `gas_constant = 287`, `specific_heat = 1005`, second-order upwind momentum, density, and energy convection with `gradient_limiter = venkatakrishnan`, and steady SIMPLE outer iterations with under-relaxation factors `0.5`, `0.3`, and `0.5` for velocity, pressure, and temperature. The implicit transport matrix remains first-order upwind, while the deferred face correction uses upwind-cell linear reconstruction. The pressure-correction equation includes consistent pressure-relaxed density storage in transient mode, upwind density/pressure convection, Rhie–Chow velocity correction, implicit total-pressure inlet linearization, and outgoing density correction at extrapolated compressible outflows.

## Run and validation

```bash
make validate-bump
```

The driver generates the meshes, runs all three cases from their prescribed initial fields, and checks:

- steady SIMPLE convergence and positive finite thermodynamic states;
- local and global mass conservation;
- subsonic fore/aft symmetry and isentropic exit Mach number;
- transonic supersonic region, shock location, and published exit Mach numbers;
- supersonic shock topology and approximate wall-profile agreement.

Results are written to:

- `validation/bump_metrics.csv`;
- `validation/data/bump_*_walls.csv`;
- `validation/figures/bump_*_mach_contour.svg` and `validation/figures/bump_*_wall_mach.svg`.

The detailed comparison is in `validation/thermal_compressible_validation.md`.

- [SU2's Inviscid Bump tutorial](https://su2code.github.io/tutorials/Inviscid_Bump/) for geometry and reference flow conditions;

The `supersonic_mach_approx.csv` values are approximate plot digitization, not tabulated author data; that limitation is stated explicitly in the validation report.
